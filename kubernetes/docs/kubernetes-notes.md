# Kubernetes Notes

This phase will introduce Kubernetes concepts by deploying the SRE Ops static site as a containerized workload.

## Goals

- Understand Kubernetes manifests
- Deploy a containerized static site
- Define Deployments and Services
- Practice health checks
- Learn basic scaling concepts
- Prepare for cloud-native deployment workflows

## Planned Components

- Deployment manifest
- Service manifest
- ConfigMap
- Health probes
- Basic troubleshooting notes

## Why Kubernetes Matters

Kubernetes is used to run and manage containers across clusters.

It helps with:

- deployment automation
- service discovery
- scaling
- self-healing
- configuration management
- production orchestration
