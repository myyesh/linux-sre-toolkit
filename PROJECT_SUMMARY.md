# SRE Ops Platform

## Project Overview

The SRE Ops Platform is a hands-on DevOps and Cloud Infrastructure project built to demonstrate modern infrastructure automation, containerization, monitoring, and CI/CD practices.

The project evolved through multiple phases covering Linux administration, shell scripting, Docker, Kubernetes, AWS, Terraform, Git workflows, and GitHub Actions.
