# Alerting Concepts

This module introduces alerting concepts commonly used in SRE and DevOps environments.

## Alert Lifecycle

Application
→ Metrics
→ Prometheus
→ Alert Rule
→ Grafana Alert
→ Engineer Notification

## Common Alert Types

### Availability

- Service Down
- Endpoint Unreachable

### Infrastructure

- High CPU Usage
- High Memory Usage
- Disk Capacity Threshold

### Kubernetes

- Pod CrashLoopBackOff
- Deployment Unavailable
- High Restart Count
